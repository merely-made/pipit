# Pipit

The maintained codec lives in [Murm, `crates/pipit`](https://github.com/merely-made/murm/tree/bb5a05374d6ac972cdf3f13ba5a417845f51a44e/crates/pipit), beside its Outrider and Signalman consumers.

Pipit remains version 0.2.0, dependency-free, no_std with optional allocation, under MIT OR Apache-2.0. Source, clip/frame identities, notices and original repository ancestry are preserved by the receiving commit. Previous releases and history remain here; new development belongs in Murm.
